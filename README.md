# FitShare 🏋️‍♂️📱

**FitShare** es una aplicación móvil diseñada para simplificar y dinamizar el seguimiento, la organización y la administración de rutinas de entrenamiento físico. La plataforma permite a usuarios (desde principiantes hasta entusiastas del fitness) gestionar sus planes de entrenamiento, visualizar sus progresos y estructurar sus hábitos deportivos de manera intuitiva y accesible.

---

## 🚀 Características Principales

- **Gestión de Rutinas:** Creación, organización y consulta personalizada de rutinas de ejercicio.
- **Seguimiento de Progreso:** Registro de actividades físicas e historial de entrenamientos.
- **Interfaz Intuitiva y Accesible:** Diseño optimizado enfocado en la usabilidad y la mejor experiencia de usuario en dispositivos móviles.
- **Estructura Escalable:** Arquitectura orientada a objetos (POO) bien definida para garantizar la extensibilidad y mantenibilidad del código.

---

## 🛠️ Tecnologías y Herramientas

- **Lenguaje Principal:** Java
- **Base de Datos / Backend:** Firebase (Cloud Firestore)
- **Paradigma:** Programación Orientada a Objetos (POO)
- **Metodología de Desarrollo:** Scrum
- **Control de Versiones:** Git & GitHub
